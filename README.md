# FOLLICA™ — landing page

Статический одностраничный лендинг под запуск продаж микроигольных патчей для роста волос в&nbsp;России (СПб → РФ).

## Стек

- Чистый HTML / CSS / JS, без сборщиков.
- Google Fonts: Cormorant Garamond + Inter.
- Инлайновые SVG‑иллюстрации — без тяжёлых картинок, без внешних CDN для изображений.

## Запуск локально

```bash
# любой статический сервер:
python3 -m http.server 8080
# или
npx --yes serve .
```

Затем открыть http://localhost:8080

## Деплой

Папка целиком — статика. Деплоится на:

- devinapps.com (`deploy frontend`)
- Vercel / Netlify / Cloudflare Pages — drag‑and‑drop.
- Любой nginx/статик‑хостинг.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка лендинга |
| `styles.css` | Дизайн‑система (токены, секции) |
| `script.js` | Интерактив: форма, реактивные SVG, reveal‑on‑scroll |

## Продукт

FOLLICA™ — растворимые микроигольные патчи для кожи головы с&nbsp;GHK‑Cu, экстрактом женьшеня, Хэ Шоу У, биотином, ниацинамидом. Ниша: отсутствует на&nbsp;WB/Ozon как отдельный продукт; на&nbsp;1688/Alibaba — цена ¥6–20/шт, MOQ от&nbsp;50 коробок, доставка авиакарго Гуанчжоу → СПб 7–12 дней.
