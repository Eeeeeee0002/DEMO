# fa:sa — landing page

Статический одностраничный лендинг под запуск продаж японских микроигольных патчей fa:sa (Cosmedy Pharmaceutical) в&nbsp;России (СПб → РФ).

## Стек

- Чистый HTML / CSS / JS, без сборщиков.
- Google Fonts: Cormorant Garamond + Inter.
- Инлайновые SVG‑иллюстрации — без тяжёлых картинок, без внешних CDN для изображений.

## Запуск локально

```bash
# любой статический сервер:
python3 -m http.server 8080
# или
npx --yes serve .
```

Затем открыть http://localhost:8080

## Деплой

Папка целиком — статика. Деплоится на:

- devinapps.com (`deploy frontend`)
- Vercel / Netlify / Cloudflare Pages — drag‑and‑drop.
- Любой nginx/статик‑хостинг.

## Структура

| Файл | Что внутри |
|---|---|

## Продукт

**fa:sa** (ファーサ) — японский микроигольный патч для кожи головы от **Cosmedy Pharmaceutical** (コスメディ製薬). 1&nbsp;коробка = 8&nbsp;саше × 3&nbsp;патча (24 патча), ~500 растворимых микроигл на&nbsp;листе. Протокол: 2×/неделю. Розница в&nbsp;Японии: ¥12&nbsp;100.

### Ниша

Не&nbsp;представлен на&nbsp;WB / Ozon / Яндекс.Маркет (проверено через API).

### Опт (закуп)

- B2B-канал Японии: [Salon Planet](https://salon-planet.jp/products/detail/12328), [Ci-Medical](https://ci-medical.com/biz/catalog_item/811905244)
- Через интермедиаторов (без японской регистрации салона): ZenMarket, FROM JAPAN, Buyee — +5–10% наценка, авиа Japan → СПб 10–14 дней.
- Рекомендуемое начало: 20–50 коробок (~€3–6k закуп).
