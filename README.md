# Arm Market · Արմ Մարկետ

Сайт-приложение для доставки армянских продуктов. Современный React + Vite + TypeScript с бордовой палитрой, декором из гранатов и корзиной с оформлением заказа.

## Что внутри

- **Hero-секция** с анимированными плодами граната и золотыми орнаментами.
- **Каталог на 25+ позиций**: лаваш, бастурма, суджух, сыры Чечил/Лори/Чанах, варенья, вина Арени, коньяк Арарат, тутовая водка, мёд, специи.
- **Поиск и фильтр** по категориям с армянскими подписями.
- **Корзина** (выдвижная панель) с количеством, бесплатной доставкой от 3 500 ₽ и модальным окном оформления заказа.
- **Секции** «История», «Доставка» и «Контакты» с орнаментами-хачкарами и бегущей строкой.
- Полностью адаптивный дизайн, шрифты Cormorant Garamond / Manrope / Noto Serif Armenian.

## Команды

```bash
npm install
npm run dev      # запустить dev-сервер (http://localhost:5173)
npm run build    # прод-сборка
npm run lint     # ESLint
npm run preview  # превью прод-сборки
```

## Палитра

| Переменная            | Цвет       | Описание                  |
| --------------------- | ---------- | ------------------------- |
| `--burgundy-900`      | `#3a0a14`  | Тёмный бордовый (фон футера) |
| `--burgundy-700`      | `#5a0f1a`  | Основной бордовый          |
| `--pomegranate`       | `#c8334b`  | Гранатовый акцент          |
| `--gold`              | `#d4a64a`  | Золото (орнаменты, бейджи) |
| `--leaf`              | `#4a7a3a`  | Зелёный листьев            |
| `--cream` / `--paper` | `#fbf4e8` / `#fff9f0` | Кремовый фон |
